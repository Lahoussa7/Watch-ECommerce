# Projet Montre - Site E-commerce de Montres

Bienvenue sur **Projet Montre**, un site web e-commerce dédié à la vente de montres de luxe et de style. Ce projet a été réalisé entièrement en "Vanilla JavaScript", HTML et CSS, démontrant une maîtrise des technologies web fondamentales sans l'utilisation de frameworks lourds.

##  Fonctionnalités Clés

- **Catalogue Dynamique** : Les produits et marques sont chargés dynamiquement à partir de fichiers JSON, permettant une mise à jour facile du contenu.
- **Système de Panier** : Ajout de produits, persistance du panier via `localStorage` et compteur de notifications en temps réel.
- **Navigation Interactive** : Menus déroulants animés et filtres par catégorie (Homme, Femme, Marque).
- **Design Responsive** : Interface adaptée aux différentes tailles d'écran (mobile et desktop) avec une attention particulière au design épuré et moderne.
- **Pages Démographiques** : Sections dédiées pour Hommes et Femmes.

## Technologies Utilisées

- **HTML5** : Structure sémantique des pages.
- **CSS3** : Design personnalisé, Flexbox, Animations, et Variables CSS pour une maintenance aisée.
- **JavaScript (ES6+)** : Logique métier, manipulation du DOM, et gestion asynchrone (Fetch API) pour les données.
- **JSON** : Stockage léger des données produits et structure du site.

##  Structure du Projet

```
.
├── CSS/            # Feuilles de style
├── HTML/           # Pages du site
├── Image/          # Assets graphiques
├── Javascript/     # Logique applicative
└── Json/           # Données (Produits, Marques, Menus)
```

##  Installation et Lancement

1.  Clonez ce dépôt :
    ```bash
    git clone [votre-url-du-repo]
    ```
2.  Ouvrez le fichier `HTML/Acceuil.html` dans votre navigateur web préféré.
    - _Note : Pour le bon fonctionnement des requêtes `fetch` (chargement du JSON), il est recommandé d'utiliser un serveur local (ex: Live Server sur VSCode)._
